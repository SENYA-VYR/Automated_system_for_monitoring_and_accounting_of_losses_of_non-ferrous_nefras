## 💬 О проекте
Проект представляет собой систему датчиков для автоматизированной системы мониторинга и учета потерь нефтяных растворителей (нефрасов). Устройство предназначено для непрерывного контроля ключевых параметров на объектах нефтегазовой инфраструктуры: нефтебазах, НПЗ, автозаправочных станциях, а также транспортных терминалах. В нефтегазовой отрасли ежегодные потери легколетучих нефтепродуктов достигают 1-3% от объема, что приводит к миллионным убыткам и экологическому ущербу. Традиционные методы учета не обеспечивают необходимой точности и оперативности, создавая потребность в современных автоматизированных решениях.

## ❗ Гипотеза проекта
Внедрение системы автоматического мониторинга на основе IoT-датчиков и предиктивной аналитики позволит снизить потери нефрасов на 20-40% за счет оперативного выявления аномалий, повысить точность учета до 99% и значительно улучшить экологические показатели предприятий.

## 🎯 Основные задачи системы
### Мониторинг параметров в реальном времени
--> Уровень продукта в резервуарах

--> Давление в трубопроводах и технологических емкостях

--> Температура нефрасов в процессе хранения и транспортировки

--> Концентрация паров углеводородов в воздушной среде

### Обнаружение аномалий и угроз
--> Автоматическое выявление утечек и несанкционированных сливов

--> Контроль превышения пороговых значений технологических параметров

--> Обнаружение признаков хищения продукта

--> Мониторинг условий взрывобезопасности

### Обеспечение надежности и безопасности
--> Резервирование каналов связи (Wi-Fi, Ethernet, GSM)

--> Шифрование передаваемых данных по алгоритму AES-128

--> Самодиагностика оборудования и датчиков

--> Буферизация данных при потере связи

## 💡 Архитектура системы
### Аппаратный уровень
--> Микроконтроллер: ESP32 с Wi-Fi/Bluetooth

--> Датчики(Ультразвуковые/аналоговые датчики уровня, датчики давления, термодатчики, газоанализаторы для углеводородов)

--> Индикация: Светодиодная система для определения состояния

### Программный уровень
--> Сенсорный модуль: Чтение и фильтрация данных с датчиков

--> Аналитический модуль: Обнаружение аномалий и прогнозирование

--> Коммуникационный модуль: MQTT-клиент для передачи данных

--> Модуль безопасности: Шифрование и защита данных

## 🔧 Ключевые функциональные модули
### 1. Модуль сбора данных
--> Многоточечный опрос датчиков по расписанию

--> Адаптивная калибровка измерительных цепей

--> Температурная компенсация показаний

### 2. Модуль обработки сигналов
--> Цифровые фильтры скользящего среднего

--> Статистический анализ данных 

--> Алгоритмы обнаружения выбросов

### 3. Модуль связи
--> Поддержка MQTT с QoS уровнями

--> HTTP REST API для интеграции

--> Автоматическое переключение между каналами связи

### 4. Модуль безопасности
--> Шифрование данных

--> Аутентификация устройств

--> Защита от несанкционированного доступа

## ✨ Особенности реализации
### Промышленная надежность
--> Watchdog timer для автоматического восстановления

--> Защита от переполнения буферов

--> Устойчивость к электромагнитным помехам

### Энергоэффективность
--> Режимы глубокого сна для батарейного питания

--> Адаптивный опрос датчиков по приоритету

--> Оптимизация энергопотребления радиоинтерфейсов

### Масштабируемость
--> Поддержка до 16 датчиков на одном узле

--> Возможность каскадного соединения устройств

--> Гибкая конфигурация под различные типы резервуаров
